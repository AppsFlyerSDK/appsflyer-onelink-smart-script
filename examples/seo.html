OneLink Smart Script V2

Organic Search (SEO) Install Attribution Demo

Requires Smart Script 2.10.2+. Set the simulated HTTP referrer (browsers do not allow setting document.referrer), then click Run Code. With SEO: true and no media-source key on the landing URL, the script maps the referrer to a *_organic_seo pid and stamps af_channel=seo. Paid signals (gclid, gbraid, wbraid, utm_source) skip SEO and fall back to defaultValue.

Input URL

To edit: make changes to the input URL in the address bar and reload the page. Changes you have made to the script below will be lost after reload.

HTTP Referrer (simulated)

Browsers block setting document.referrer. This field writes the same store Smart Script uses (ss_webReferrer) so you can try search-engine hosts. Production sites do not need this field — the library reads document.referrer on load.
